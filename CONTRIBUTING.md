# Contribuer à FoodFlow

Point d'entrée : https://github.com/HashCode-Reboot/hashcode-contributors.

Les contributions doivent partir d'un problème documenté. Les données terrain doivent être obtenues légalement et leur provenance conservée. Ne pas présenter une prédiction comme un fait.

Une PR décrit le problème, la méthode, les données, les tests, les limites et l'impact mesurable attendu.
