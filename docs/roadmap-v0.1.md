# Roadmap V0.1

Foundation: map the supply chain, loss points, actors and data constraints.

Architecture: define product/batch/location/transfer/loss-event models and provenance.

MVP: deliver batch tracking, loss-event capture and actionable alerts.

Validation: test representative supply-chain scenarios and measure losses detected or avoided.

Release: complete data-quality, security, tests, documentation and impact gates before V0.1.
